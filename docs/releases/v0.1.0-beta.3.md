# Rustorrent 0.1.0 Beta 3

Fixes for magnet links, the search view and seeding, plus one consistent logo.

![Rustorrent 0.1.0 Beta 3](https://raw.githubusercontent.com/josusanmartin/rustorrent/v0.1.0-beta.3/docs/screenshots/hero-light.png)

## Download

- **Apple silicon:** `Rustorrent-0.1.0-beta.3-arm64.dmg`
- **Intel or Apple silicon:** `Rustorrent-0.1.0-beta.3-universal.dmg`
- **Linux x86_64:** `rustorrent-0.1.0-beta.3-linux-x86_64.tar.gz` (needs OpenSSL 3)
- ZIP archives of the app and `SHA256SUMS.txt` are attached below. The app requires macOS 11 or newer.

The app is ad-hoc signed for integrity. It is **not Developer ID signed or Apple notarized**, so on first launch macOS may ask you to allow it: right-click the app, choose **Open**, or allow it in **System Settings › Privacy & Security**.

## Fixed

**Uploading and seeding**
- **Local trackers work.** A tracker on your own machine or home network was refused as "not publicly routable", so it never returned peers. HTTP trackers now reach local addresses, as UDP trackers already did. Through a proxy, only public trackers are used.
- **Peers on your network are kept.** Peers with private addresses (such as 192.168.x or 10.x) from trackers, peer exchange and magnet links were discarded, so two computers on the same network could not find each other. They are now used; the DHT still ignores them.
- **A tracker failure is no longer an error.** A transfer whose tracker could not be reached was shown as "error" while the DHT, peer exchange and local discovery could still find peers. The tracker message is now a note in the details, and it clears when a tracker answers.

**Magnet links**
- **No more time-outs.** A magnet link whose metadata could not be found straight away failed after a time-out. Rustorrent now keeps searching, waiting 5 seconds at first and up to a minute between attempts, until the metadata arrives or you stop the transfer.

**Search**
- **No false "no plugins" warning.** The search view said no plugins were installed while the bundled plugins were still loading. It now shows "Loading search plugins…" until they are ready.

## Changed

- **One logo everywhere.** The macOS app icon, the window header, the browser tab icon and the README now share the same blue download mark. The app icon is generated from `macos/AppIcon.svg` by `macos/create_icon.sh`.

## Validation

- **Rust:** 517 unit tests, 9 process tests and 20 transport tests.
- **Real processes:** 8 transfer and crash-recovery scenarios.
- **Transmission interoperability:** a new test in which Rustorrent connects out to a leecher on a LAN address and seeds it the whole file.
- **Browser flows** with WCAG A/AA accessibility checks.
- **CI** covers Linux, macOS and Windows, Rust 1.89, dependency advisories and the license notice.
